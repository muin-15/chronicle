# Chronicle

Chronicle is a detective visual novel build using Ren'Py and python.The game starts with two students Taiju and Hikari walking on there way to school for the graduation ceremony.There they come to know the Academic award got stolen.The students correct choices would reveal the mystery.

No use of Ai.

**Estimated playtime:** 30-60 minutes

|A|Auto mode|

## How to play
### For players
1.First download the zip file of the game from the given link from Itch.io.

2.Then unzip the downloaded zip file.If you won't unzip the file then the game won't run.

3.Now run the game file like double click chronicle.exe for Windows.

### For Developers
1.Download the [Ren'Py SDK](https://www.renpy.org/).

2.Move chroncile folder to your Ren'Py projects directory.

3.Open Ren'Py laucher,search for chroncile and click 'Lauch project'.
